# Cайт-общалка, позволяющий общаться между людьми

## Задание

Макет сайта, которого вам предстоит разработать, лежит в файле "DjangoLearn.pdf"

## Примечание

- Разделите сайт на приложения:
	- users
	- communication
	- homepage

- Админ панель доступна только superuser

- Поле "работа" - это отдельная таблица Work с полем Name (выборка из этих работ, как комбобокс) 

- Дата рождения - формат дата

- Для работы с таблицей User используйте встроенную таблицу auth_user 
> пример можно взять <a href="https://github.com/124476/Center_FSP/blob/main/center_fsp/users/models.py">от сюда</a>

- Загрузите на гитхаб
> не забудьте, что сайт должен выноситься в отдельную папку, а не сразу в корень репозитория

- Оформите readme:
	- Напишите про сайт
	- Описание запуска
